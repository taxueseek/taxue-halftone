# 反模式雷达（命名篇）

> 反模式一定要**命名**。给一个模式起名字,agent 才能在生成图和写 prompt 时把它当成一个可指认的对象去扫描,而不是靠"别做那种东西"这种模糊约束。这是从 Vercel `design.md` 学到的关键一步,但所有命名都落在 taxue-halftone 自己的六不变式与限墨语言里,不借用外部设计体系。

> 用途:写五段 prompt 之前跑一遍「反模式雷达」,逐模式问一句"我的 description 里有没有出现这个信号",命中就先改、再出图。

每个模式三栏:**名字(信号) → 在图上看到的签名 → 正确替代**。

## A. 色调层(Ink / Color)

| 名字 | 视觉签名(命中即警觉) | 正确替代 |
|---|---|---|
| `third-color-leak` 第三色漏色 | 画面出现既非两支持定墨、又非叠印、也非 Mist 的独立色相 | 任何色都必须能指认来自哪支墨;第三色只允许是「两支墨的叠印」或「Mist(主墨浅阶)」,禁止新增 hex |
| `gradient-masquerade` 渐变冒充网点 | 看似顺滑空气渐变,放大后没有规则点/网纹结构 | 渐变必须落到结构上:AM 网点点径有限频次地变化,或 1-bit 硬边平阶;禁止无点模糊过渡 |
| `neon-spray` 霓虹泼彩 | 高饱和荧光色、色块外发光、纸面没有呼吸 | 回落到 ≤2 墨 + 纸;色相从 §2 起点色里选 |
| `full-color-photo` 全彩照片 | 连续全彩阶调、>2 色相、没有印刷限制感 | 先降为 1-bit 剪影或双色 + 纸,再加网点/平阶 |
| `auto-vintage` 自动做旧 | 泛黄、grain+刮痕+咖啡渍堆叠、边缘烧灼、噪点 | 当代纸 + 干净网点;做旧感来自「一次套准偏移」或「一次并网」这种工艺缺陷预算,一次只选一族,不堆滤镜 |
| `fake-cmyk-riso` 假 CMYK 扮孔版 | 四色套印灰平衡、青品黄黑角标看起来像四色印刷机 | Riso 逻辑是 ≤2 专色 + 叠印,用专色角色而不是四色平衡 |

## B. 机制层(Mechanism / Structure)

| 名字 | 视觉签名 | 正确替代 |
|---|---|---|
| `same-angle-stack` 全通道同角 | 两支墨同一加网角度,交叠处出 moiré 水纹 | 双色差 ≥30°,网角错开 |
| `color-halftone-on-rgb` RGB 上套滤镜 | 在彩色照片上直接套 Color Halftone 滤镜,出不规则彩色噪点团 | 先在色域上降为 1-bit / 双色,再套印刷结构 |
| `mechanism-as-mood` 机制当情绪词 | prompt 里是「Riso 风」「duotone vibes」「胶片感」,却没有角/点/密度/墨的可指认值 | 写成可指认字:AM 网点 45°、1-bit 硬阈值、凸版压痕、photogram 剪影,配具体值 |

| 名字 | 视觉签名 | 正确替代 |
|---|---|---|
| `centered-template` 居中模板 | 标题居中、四周对称、无裁切、无撞物、结构松散 | 一物主导 + 至少一边裁切 + 字撞物;纸为字留口袋 |

| `logo-qr-screen` 商标/二维码加网 | Logo 或二维码被网点化,出现摩尔纹或不可识别 | 商标/二维码用实色或 type-off,不上网 |

## D. 主体层(Subject)

| 名字 | 视觉签名 | 正确替代 |
|---|---|---|
| `stock-hero` 广告英雄人像 | 无来源、完整构图、面向镜头、眼珠清晰的全彩色人像 | 用剪影 / 1-bit / 局部裁切,不引入完整英雄人像 |
| `reference-reprint` 复刻参考图 | 逐字复刻某张参考图独有的字句、排版、构图 | 吸收其原则,不复制其具体字句与排版 |

|---|---|---|
| `sticker-collage` 贴纸拼贴 | 独立圆角贴纸、投影、黏贴感,边界能"拔起" | 撕纸拼贴要三层结构 + 专色场 + 黑白半调主体;边缘是撕口不是圆角 |

| 名字 | 视觉签名 | 正确替代 |
|---|---|---|
| `sales-cta` 销售 CTA | 促销按钮、「立即购买」「限量抢购」 | 观察/公告语气,保存信息层级而非转化 |
| `hero-vector-poster` 矢量平涂网红海报 | 扁平矢量、几何渐变、大色块描边、模板感 | 印刷机制的结构 + 纸白 |

## 雷达扫描流程

写五段 prompt 后,逐名过一遍上面 18 个模式。命中任一信号:

1. 先说"此处命中 `xxx`,信号是 `yyy`"。
2. **只改一段**(在它所属的那段里改),不重写整份 description。
3. 改完回到对应模式的「正确替代」对照,确认替换方向正确。

雷达扫描的答案判语与本技能整体一致:改完后必须仍能说清「哪支墨、哪个角或哪一层、纸在哪」。
