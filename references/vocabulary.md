# 印刷术语反查词典

> 用户描述往往模糊("像老挂历""颜色挤在一起""很安静")。这张表把模糊词反查成本技能的精确术语,让用户和 agent 在同一个词上对齐。反查方向:用户说 → 本技能术语(机制 / 风格 / 六轴取值)。

> 结构借鉴自 animation-vocabulary 的"模糊→精确术语"思路,但所有术语都是 taxue-halftone 自己的印刷语言,不借用外部动效词。

## 用户说「像……/有点……」 → 本技能术语

| 用户模糊词 | 本技能术语 | 落在哪 |
|---|---|---|
| 像老挂历 / 有点糙 / 能摸到颗粒 | 大网距 AM 半调,网点点径大 | 机制=am_halftone;风格偏 `riso_zine` 或 `editorial` |
| 颜色能挤出来 / 颜色压在一起变深 | overprint_duotone(叠印),交叠处两墨互叠成深色 | 布尔=overprint;风格 `filmstack` |
| 颜色很安静 / 留白很多 / 呼吸感 | 大空纸 + 一物小 | 风格 `swiss` 或 `riso_zine`(空纸 70–90%) |
| 颜色就一两个、但很有分量 | pure_one_ink 单墨 | 布尔=单墨;风格 `polish` |
| 像老照片扫描 / 高反差 | photogram_stencil 1-bit 硬阈值 | 机制=photogram_stencil;风格 `polish` |
| 像杂志那本《Cereal》 | 复古编辑印刷风,一物主导 + 字撞物 + 纸露白 | 风格 `editorial`(基准) |
| 像波兰老海报 | 高反差剪影,字即物 | 风格 `polish` |
| 像胶片负片叠在一起 | 字图共享一层,选交叉网角 | 机制=film_stack;风格 `filmstack` |
| 像标本 / 像档案卡 | 规整图像板 + 多栏图注 | 风格 `archival` |
| 像撕坏的拼贴 | 三层撕纸拼贴,专色场 + 黑白半调主体 | 机制=torn_paper_collage;风格 `imperfect_collage` |
| 像剪纸 / 像窗花 | 中式剪纸剪影,白色负空间镂空刻画细节 | 机制=paper_cut_collage;风格 `paper_cut_group` |
| 像网点剪纸 / 剪纸加网 / 双色丝网剪纸 | 剪纸窗花轮廓,形体内部粗圆网点铺形,暗部不断网 | 机制=am_halftone;风格 `paper_cut_halftone` |
| 像洞洞板 / 孔版 | 孔版网点,纸张微透 | 机制=am_halftone;风格 `riso_zine` |
| 像晒蓝图 | 蓝晒机制,靛蓝单色 + 纸白 | 单色机制,靛蓝 hex |
| 想让它有点"缺陷感" | 一次套准偏移 或 一次并网 | 工艺缺陷预算,只选一族 |
| 想让它"像真印刷" | 纸色 + 角色墨 + 叠印 + 机制痕迹 | 六不变式全套 |
| 想让它"再高级一点" | 多用纸白,收着动 | volume=image_lead,空纸调高 |

## 反向:本技能术语 → 一句大白话

| 本技能术语 | 大白话 |
|---|---|
| am_halftone | 常规印刷半调,用规则网点模拟深浅 |
| photogram_stencil | 高反差剪影,像把物件直接放纸上曝光 |
| film_stack | 字和图叠在同一层,共用一次印刷 |
| torn_paper_collage | 三条撕纸边、三层结构,纸口不规则 |
| paper_cut_collage | 刀口剪影层层叠,细节靠白纸镂空,无网点无投影 |
| overprint_duotone | 两支墨直接叠,交叠处变深 |
| knockout | 两墨不叠,前一包住后一,纸在缝里露 |

## 用词纪律

- 用户词映射到机制后,若仍模糊,先报出"我把它理解成 XX(机制名)",让用户确认再出图。
- 反查只用来**对齐**,不改变六不变式。任何机制都要落到角/点/密度/墨,不能只停在"像老挂历"这种词上。
