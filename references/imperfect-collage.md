# 不完美印刷拼贴（imperfect_collage）

> 有意不完美的编辑型印刷拼贴。本质：把「编辑海报」的秩序和「手工撕纸」的粗粝叠成三层结构，粗粝只在图像层，信息层永远清醒。风格走 `styles/imperfect_collage.json`，常用画幅与安全区见 `platform.json`。

## 六轴落地（对应 styles JSON）

| 轴 | 本风格取值 | 为什么 |
|---|---|---|
| 纸 | ground_warm_white `#FAF7F0` | 暖白纸底是信息卡与撕纸基底，纸不算墨 |
| 墨 | chromatic_plus_black：专色场 `#1DA1F2`（70–85%）+ 黑 `#141414`（15–30%）+ 跳色 `#F7B500`（≤5%） | 大面积专色场做图像层底色与揭示色块；黑做半调主体与信息卡文字；跳色是本风格专属第三通道，只做小面积揭示/叠印交叉/高光，不进主体结构 |
| 布尔 | overprint | 允许 ≤1mm 套印错位与半透明叠印；第三色只能来自叠印混色或 ≤5% 小面积揭示 |
| 机制 | torn_paper_collage | 撕纸拼贴层叠：纸底/专色场/半调主体三层，撕纸边只揭示或分区 |
| 行为 | still | 主体静置陈列，焦点稳定 |
| 音量 | balanced | 图像层与信息层分区（常见上图下卡），焦点在图，字完整可读 |

## 艺术总监方案（接案表单）

输入面板（用户填写，缺省按默认）：

- 主体：`{主角}`（一个明确的主角：人物/动物/静物）
- 语义道具：`{道具}`（1–3 件能解释主题的物件，缺省自拟 1–2 件）
- 媒介与画幅：`{画幅}`（产品功能页/社媒横幅/海报；缺省 3:4 竖幅）
- 情绪：`{情绪}`（幽默、紧迫、好奇、勇敢、温暖……）
- 表达强度：`{强度}`（1–5，缺省 2）
- 可选原创短文案：`{文案}`（≤6 字/词；无品牌、商标、现成口号；缺省按主题发明）
- 主色与跳色：`{主色}`（缺省饱和蓝 `#1DA1F2`）+ `{跳色}`（可选）

## 创作规则（六条）

1. 主题先翻译成一个直接、带一点机智的视觉隐喻；只用一个主角 + 1–3 个道具，不做素材拼盘。
2. 用高反差编辑摄影或静物摄影作图像原料：阴影转成清晰可见的粗 AM 新闻纸网点、丝网颗粒、轻微复印噪点与轻微油墨不均，不用磨皮渐变。
3. 三层必在：暖白纸底（Ground）→ 大面积专色场或图片层 → 前景黑白半调主体。用 1–2 道不规则撕纸边、局部遮挡或越界裁切制造「信息被揭开」的路径。
4. 颜色 = 黑 + 暖白 `#FAF7F0` + 主色与跳色，高饱和专色总共不超过三种；允许轻微套印错位与半透明叠印；禁止彩虹渐变、霓虹故障、塑料 3D。**跳色通道**：本风格不受「≤2 墨」约束，跳色面积 ≤5%、只做小面积揭示/叠印交叉/高光，须写 HEX，不进主体结构。
5. 字体只做原创粗新怪诞无衬线（Grotesk）。有文案必须完整、简短、易读，与功能信息分层；不生成真实品牌 Logo、鸟类标志、现成社交平台界面或受保护口号。
6. 粗粝只存在于图像层；信息层必须有留白、稳定网格、清楚层级和一个明确焦点。强度越高，才增加重复短语、局部文字碎片和纵向撕裂。

## 强度分级

| 强度 | 空纸 | 撕边 | 碎片/撕裂 |
|---|---|---|---|
| 1 | 极多（55%+） | 0–1 道 | 无 |
| 2（默认） | 大留白（30–55%） | 单撕边 | 无 |
| 3 | 明显留白 | 1–2 道 | 无 |
| 4 | 收紧 | 1–2 道 | 重复短语碎片或一处纵向撕裂 |
| 5 | 最紧 | 2 道 + 局部遮挡 | 碎片 + 撕裂并存，焦点不丢 |

## 锁定句（compiled prompt 内保留 2–3 条）

- 网点必须粗到远看仍在；撕纸边是揭示不是装饰。
- 图像层粗粝（新闻纸颗粒 + ≤1mm 套印错位），信息层清醒（留白网格、单一焦点）。
- 暖白纸 `#FAF7F0` 不算墨；专色场是墨 0 之上的第一层。

## 硬避免（本风格专属）

茶渍复古、剪贴簿堆料、无网点平滑矢量、标题乱码、真实社交平台名/Logo/鸟标/Chirp/App 界面、可指认的官方空状态构图、中英混排。
