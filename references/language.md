# 多语言规则

本技能以用户语言为母语。加网是少阶装置，对笔画宽度极苛刻。CJK 比 Latin 更怕网。

1. **用户给出的文案**：逐字保留原语言，禁止翻译、禁止加标点润色。
2. **需要发明显示句时**：使用用户当前对话语言；中文请求 → 中文 2–8 字；英文请求 → 英文 2–8 词；混合请求 → 主声部用用户指定语言。
3. **双语**：一个语言主声部，另一个支持（更小、更弱）。禁止两行同样大的说明书。CJK 光学字号 ≥ Latin 的 110–130%。
4. **后期叠字（默认）**：任何需要阅读的字（内文、日期、credits、URL、小标）、所有低于显示尺寸的 CJK、Logo、数字、图注、还要经社交压缩的字。画面留空带，后期上真字。
5. **字可进网（与图同版）仅当**：超大标题，笔画宽度 ≥ 2–3 个网距；或故意字图一体。CJK 超大标题仅 ≤8 字且准备逐字校对；失败一次后改 type-off。禁止对汉字做 halftone fill。
6. **字体**：CJK 优先黑体/Gothic；宋/明禁止反白小字与加网。拉丁粗 grotesk 可略小，小字仍实地。竖排：中文可竖排当图像，且不要压在 45° 网上；拉丁禁止观光店式竖排。
7. **套印**：深色小字纯黑 overprint；浅色字在深网上 knockout + 细 trap；白字 = 纸，只能 knockout。小字禁止双色套印。
8. **发明文案语气**：观察 / 记录 / 私语 / 宣言；禁销售口号、CTA、励志鸡汤。
9. **type-in 是印刷事件**：写墨量（浓/中/淡/隐）、所在层（沉底 under / 同层 same / 浮面 over）、最多一处「破」（断墨、末字没印上）。禁止只写字体名。字越大墨越淡。CJK 仍优先 type-off。
10. **进画面的字最多一个角色**：落款（安静签名，不解释）/ 呼应（位置或走向跟主物发生关系）/ 节奏（字跟着消散或加密）。禁止标题+副标题+装饰小字三层。
11. **标点与混排**：中日用「」『』；不要把中文改成英文引号。禁止未请求的英文翻译行。日文竖排（縦書き）可当图像，仍不要压在 45° 网上。
12. **两专色包装近亲**：墨 100% 黑 + 一支专色 + 和纸 Ground；箔金不进本技能。
13. **字图音量的 CJK**：只把 1–3 个字吹到物的尺度；不要把整句当 GO!。标点当物只用一次（！、「」）。汉字禁止 duotone fill。
