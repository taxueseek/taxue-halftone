# 场景路由

先选场景，再锁比例、观看距离与印版。未列出的题材归入最接近的一行，不要发明杂烩版式。每种场景先满足 `subject.json` 的主体结构链，再谈其他。

## 建议避开的高使用率组合

「钴蓝+陶土骑行夏日」这类组合能被轻易识别为「典型半调海报」，失去场景区分度。用户没点名时，把配额留给中文主声部、肖像/播客封面、建筑、票券、无图纯字。

## 场景表

| 场景 | 典型比例 | 张力 | 版式偏好 | 印版提示 |
|---|---|---|---|---|
| 活动 / party / 夜市 | 3:4 | assertive 或 balanced | type-led / ruled info | 信号色主墨 + 冷色辅墨 |
| 城市散步 / 旅行 / 骑行 | 3:4 | relaxed | editorial / image field | 互补双色；巨物裁切。勿默认钴蓝+陶土 |
| 肖像 / 个人照片转绘 | 3:4 或 4:5 | balanced | image field / editorial | 纯单墨或彩墨+黑；round 点；保高光纸白；主体结构链优先（清晰面部+头颈肩+躯干+一组连续手/身） |
| 包装 / 物件 | 1:1 或 3:4 | balanced | object field / specimen | 物件重复或单标本；禁虚构品牌；完整形制+功能件+材料连接 |
| 植物 / 标本 / 观察笔记 | 3:4 | relaxed | archival plate / journal | 植物绿系单墨或绿+黑；花/枝/根连续生长链 |
| 夜景 / 展览 / 摄影展 | 3:4 或 16:9 | balanced | editorial / type-led | 深蓝/炭黑；当代纸 |
| 音乐 / 播客 / Playlist 封面 | 1:1 | assertive | editorial | 默认字图音量；禁止全身肖像+大标题双开 11；纸白当第三印 |
| 社媒封面 / 小红书 | 3:4 或 4:5 | relaxed | editorial | 上 1/4 可留后期标题带 |
| 博物馆 / 展览图 | 3:4 或 16:9 | balanced | ruled info / type-led | 炭黑+信号色；无米色怀旧 |
| 文学短句 / 无图诗页 | 3:4 | assertive 或 relaxed | type-led / typographic object | 字即主体；2–8 字/词；中文主声部优先 |
| 服装 / 周边印花概念 | 1:1 或 3:4 | balanced | object field | 物件重复；禁虚构商标 |
| Zine / 杂志内页 | 3:4 | relaxed | journal / archival | 彩墨+黑；正文 type-off |
| 作品集 / 展览墙 | 16:9 或 3:4 | balanced | type-led / ruled | 当代纸；无自动做旧 |
| 建筑 / 混凝土 | 3:4 或 16:9 | balanced | image field / archival | 炭黑 + 信号红；材质清楚才加网；结构边硬（窗/几何不融化） |
| 票券 / 请柬 / 菜单 | 3:4 或 1:1 | balanced | ruled info | 可读字后期；网只给主图或色面 |

## 主体面积经验

标本/落款 10–30%；肖像/封面 22–50%；活动信息 32–55%；极疏 zine 10–24%。勿与空纸合计超过 100%。
