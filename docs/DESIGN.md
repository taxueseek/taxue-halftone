# taxue-halftone 设计说明

> 半调海报 · 艺术封面

> 怎么把「印刷工艺的规范」做成「能被机器校验的系统」。这份文档记录第一性原理、MECE 切轴与量化依据。维护者改任一 json 时先读这里。

## 一、问题重定义

原始诉求：做一张好看的限墨海报。

但「好看」不可校验，无法复用。把它重定义为：**在有限油墨（≤2 墨 + 纸）的前提下，输出一张满足一组可验证不变式的印刷品。**判定标准从「看起来正不正常」换成「能不能指认每个元素的物理来源」。

由此导出核心不变式：**如果不指出每块颜色来自哪支墨、哪个角或哪一层阶、纸在哪里露出，就不是本系统。**

## 二、六不变式（MECE 切轴）

「规范」不是一段描述，而是一组互斥且穷尽的决策轴。任何一张图（无论什么风格）都必须各自回答一次。风格 = 六个轴各取一组确定值形成的指纹。

| 轴 | 回答 | 为什么不可少 |
|---|---|---|
| 1 纸(Ground) | 纸是哪块、什么色 | 纸是「色」，是墨 0，不回答则整册是染色 |
| 2 墨(Ink/Mist) | 哪几支、各干什么 | 主/辅/雾角色决定层次是否通透 |
| 3 印刷布尔 | 两色相交怎么处理 | knockout/overprint/trap，不回答则第三色失控 |
| 4 机制 | 用什么印刷语言 | AM/1-bit/剪影/凸版/胶片叠层，一次一个 |
| 5 主体行为 | 势往哪走 | still/dissipate/densify/horizon/vertical-extend |
| 6 字图音量 | 谁大声谁退 | 字大声则图退，禁止双开 11 |

互斥性：六轴彼此独立，改一轴不污染另一轴（如换机制不改墨色）。
穷尽性：六轴覆盖了「色、版、势、字、图、边」全部必需决策；缺任何一轴，图都不可判定。

## 三、两个独立约束系统

六轴之外还有两个系统，它们不改变六轴取值，但决定「是否能用」：

- **主体结构链**（`subject.json`）：决定主体可识别性。遮住标题后 3 秒认出。这不是六轴之一，而是「做出来能不能看」的底线。
- **平台画幅**（`platform.json`）：决定多尺寸是否被裁坏。每尺寸单独构图，母图不硬裁。

设计上把这两者独立出来，是为了让「风格鲜明」和「主体/尺寸可用」解耦——你可以换任意机制，但主体识别和画幅安全是前提，不可因风格而牺牲。

## 四、量化约束（校验器检查的数值）

每个轴都落到可验证的数值范围，超出即判越界：

- 纸：底衬色 `counts_as_ink=false`，HEX 大写合法。
- 墨：主 70–85%，辅 15–30%；≤2 墨（`pure_one_ink` 只 1 墨）。
- 印刷布尔：必须 ∈ {knockout, overprint, trap}。
- 机制：一次一个，`mechanics.json` 里 default = am_halftone。
- 空纸：每风格声明 `empty_paper` 区间（如 editorial 25–55%，riso_zine 70–90%）。
- 比例：`X:Y` 或带小数如 `2.35:1`。

## 五、风格 = 确定的六轴取值（鲜明的来源）

「鲜明」不是模板，而是「六轴都有确定值且各轴取不同值」。`styles/*.json` 存的是取值组合：

- `editorial`：AM 半调 + 字撞物 + 纸露白（本技能的核心，继承自最稳定的视觉）。
- `polish`：1-bit 高反差 + photogram 剪影 + 字即物。
- `swiss`：柔网摄影 + 实色字 + 纸白，功能主义。
- `riso_zine`：极疏空纸 70–90% + 粗线点 + 落款小字。
- `filmstack`：字图同一张膜（胶片叠层）。
- `archival`：标本 + 规整图像板 + 多栏图注。

每个风格被校验器强制「六轴齐全 + 跨文件引用存在 + ≤2 墨」，缺一即不通过——这是「规范」与「鲜明」能被同时保证的机制。

## 六、校验器职责

- `validate_design_system.py`：校验数据层结构（id 唯一、schema_version、HEX/RATIO、必填字段、默认引用存在）。
- `validate_styles.py`：校验风格六轴齐全、引用的机制/墨/布尔在数据层存在、≤2 墨、quantified 百分比合法。
- `validate_evals.py`：校验 eval 引用的风格存在、断言与风格定义一致（防止断言和配方脱节）。

三套构成闭环：改数据层 → 校验结构；改风格 → 校验完整性与引用；写 eval → 校验断言与配方一致。

## 七、验证与回归

`run_tests.sh` 一次跑三套。新增一个风格时：加 `styles/<id>.json` + 补一条 `evals` + 确认六轴齐全与引用存在。改任一不变式时：同步改对应 json + 校验器 + 相关 eval，保持数据集一致。

## 八、边界（本系统刻意不做）

- 全彩照片、UI、数据图表、精确商标复刻、法务级逐字排版。
- 多墨（>2）专色系统；真印厂工艺规范（LPI/网版由生产决定，本系统只为数字封面建立可信印刷视觉）。
- 把印刷机制当情绪词直接写进 prompt（机制是结构，不是滤镜名）。
